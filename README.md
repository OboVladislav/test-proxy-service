# Proxy Service

Веб-сервис для управления прокси-доступом с регистрацией, личным кабинетом и десктопным клиентом.

## Стек

- **Backend:** FastAPI + SQLAlchemy + PostgreSQL
- **Очереди:** Celery + Redis
- **Frontend:** Vue 3 + Vuetify (CDN, nginx)
- **Desktop:** Python + Tkinter
- **Контейнеризация:** Docker + docker-compose

---

## Как запустить проект

### Требования

- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- Docker Compose (входит в Docker Desktop)

### Запуск

```bash
git clone <url-репозитория>
cd proxy

# Создать файл с переменными окружения
cp .env.example .env

docker-compose up -d --build
```

Первый запуск скачивает образы и устанавливает зависимости — занимает 1–3 минуты.

### Проверка

```bash
docker-compose ps
```

Все пять контейнеров должны быть в статусе `Up`:

| Контейнер | Описание | Порт |
|-----------|----------|------|
| proxy-frontend-1 | Веб-интерфейс (nginx) | http://localhost |
| proxy-backend-1 | API (FastAPI) | внутренний |
| proxy-db-1 | База данных (PostgreSQL) | 5432 |
| proxy-redis-1 | Брокер задач (Redis) | 6379 |
| proxy-celery-1 | Воркер очередей (Celery) | — |

### Остановка

```bash
docker-compose down
```

### Swagger (документация API)

Открыть в браузере: [http://localhost/docs](http://localhost/docs)

## Как зарегистрироваться

### Через веб-интерфейс

1. Открыть [http://localhost/#/register](http://localhost/#/register)
2. Ввести **email** и **пароль** (и подтверждение пароля)
3. Нажать **«Зарегистрироваться»**
4. Появится сообщение: *«Письмо с ключом отправлено на почту»*

> В текущей конфигурации письмо выводится в лог Celery-воркера (console backend).  
> Посмотреть «письмо»:
> ```bash
> docker logs proxy-celery-1
> ```

### Через API (Swagger)

```
POST http://localhost/auth/register
{
  "email": "user@example.com",
  "password": "yourpassword"
}
```

## Как получить ключ активации

### Способ 1 — Личный кабинет (после входа)

1. Открыть [http://localhost/#/login](http://localhost/#/login), войти в аккаунт
2. Перейти в [Личный кабинет](http://localhost/#/profile)
3. Ключ отображается в строке **«Ключ активации»**
4. Нажать иконку копирования справа от ключа

Если ключ уже использован — нажать **«Обновить ключ»**.  
Новый ключ будет сгенерирован и появится в ЛК (и в логе Celery).

### Способ 2 — Лог Celery (для разработчиков)

```bash
docker logs proxy-celery-1 | grep -A 5 "ACTIVATION KEY"
```

Пример вывода:

```
[EMAIL] To: user@example.com

========================================
  Proxy Service — письмо активации
========================================
Здравствуйте!

Ваш ключ активации для подключения к прокси-серверу:

  eb7ed8558c79b9c0f2283401dd3f8a11

Введите его в десктопном приложении Proxy Client, нажмите «Подключиться».
```

## Как запустить десктопное приложение

### Требования

- Python 3.9+
- Запущенный проект (`docker-compose up -d`)

### Установка зависимостей (один раз)

```bash
pip install requests websocket-client
```

> На Windows, если используется несколько версий Python:
> ```bash
> py -3 -m pip install requests websocket-client
> ```

### Запуск

```bash
cd desktop
python app.py
```

> На Windows:
> ```bash
> py -3 app.py
> ```

### Использование

1. Вставить ключ активации в поле **«Ключ активации»**
2. Нажать **«Подключиться»**
   - Если ключ валидный → статус изменится на **«Подключено»**, появится адрес прокси
   - Если все прокси заняты → сообщение «Все прокси заняты»
   - Если ключ неверный или уже использован → сообщение об ошибке
3. Статус подключения обновляется в реальном времени через **WebSocket**
4. Для завершения нажать **«Отключиться»** — прокси освободится для других пользователей

### Возможные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Нет связи с сервером | Docker не запущен | `docker-compose up -d` |
| Все прокси заняты | Нет свободных VM | Подождать или освободить через ЛК |
| Неверный ключ | Ключ уже использован | Обновить ключ в ЛК |
